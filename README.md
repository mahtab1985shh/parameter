# پارامتر

آخرین طراحی سامانه پارامتر در فایل `parameter-v34-login-sharp.html` قرار دارد.

برای مشاهده، فایل HTML را همراه با `parameter-login-construction-v34.png` در یک پوشه نگه دارید و HTML را در مرورگر باز کنید.

آخرین تغییر: تبدیل انتخابگر مشترک تاریخ مدیریت طرح از پنجره وسط صفحه به دراپ‌دان کنار فیلد. صحت نحوی اسکریپت بررسی شده؛ تست تصویری این تغییر هنوز انجام نشده است.

تاریخچه نسخه‌ها در بخش Commits همین ریپازیتوری نگهداری می‌شود.
